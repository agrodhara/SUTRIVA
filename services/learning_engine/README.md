# Learning Engine

Offline experimentation module for transaction representation learning.

This is intentionally separated from the live Alpha decision API. The Alpha product can use deterministic rules and explainable features first. Learned representations enter production only after offline validation, governance review and release approval.

## Roadmap

1. Aggregate baseline
2. Simple merchant/category/amount embeddings
3. Sequence representation prototype
4. Hybrid aggregate + embedding model
5. Drift, calibration and explainability review

## Initial research program alignment

- Paper 2: transaction sequence representations
- Paper 3: dynamic financial vulnerability state
- Paper 4: graph/relational representation later
- Paper 5: governance after scars
