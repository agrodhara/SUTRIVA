| 2026-09-20 | Borrow Better 1.1A server-authoritative illustrative rate. The canonical customer-facing copy is `Illustrative annual rate: 14%. Configured by policy; not a loan offer.` The rate is display-only and never customer-editable, and there is no "Change rate" control. The backend-configured policy rate is authoritative for every calculation. If a client omits the rate, the backend applies the configured rate. If a client supplies the exact configured rate, the request may be accepted for backward compatibility. If a client supplies a different rate, the request returns `422`, and a mismatched client rate is never used in any calculation. Step 4 displays the rate echoed by the backend response. The Step 3 frontend may initially display the bundled value from the same shared policy configuration (`shared/track11_config.json`), but that value is provisional until the backend EMI preview responds and must never be treated as an independent calculation authority. Production deployment must keep the PWA and API policy configuration synchronized, and PWA/API rate-configuration consistency is a release gate and a monitoring responsibility. This decision intentionally supersedes the previous behaviour that honoured arbitrary client-supplied rates. | The final Borrow journey defines the illustrative rate as policy-controlled. Allowing customers or callers to change the calculation rate would contradict the journey, make displayed comparisons inconsistent and risk presenting results under an unauthorised assumption. | DECIDED |
