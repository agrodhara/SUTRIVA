# Acceptance Criteria

## Product feature done

- User journey is clear on mobile.
- Copy does not imply loan approval.
- No fulfilment path is exposed.
- Result includes reason codes.
- Errors are readable.

## Engineering done

- Code runs locally.
- Relevant tests pass.
- API contract is updated.
- No secret or real data is committed.
- No decision logic is hidden in frontend.

## Governance done

- Policy version is visible where relevant.
- Audit event is generated where relevant.
- Decision log is updated for material choices.
- Hard-fail rules are not violated.
