# Security Do Not Touch List

Do not implement or change these without explicit senior approval:

- Authentication provider.
- OTP or phone verification.
- Production database.
- AWS IAM policies.
- Secrets handling.
- File upload storage.
- Real customer data processing.
- Consent language for real users.
- Data retention/deletion logic.
- Any lender integration.

## AI tool restriction

Never paste real financial data, identity data, bank statements, account numbers, PAN, phone numbers or credentials into AI tools.
